# 🚀 MockPilot AI — Render Deployment Guide

## Architecture Overview

```
MockPilot AI on Render
├── Backend Service (FastAPI)
│   └── https://mockpilot-api.onrender.com
└── Frontend Service (Streamlit)
    └── https://mockpilot-frontend.onrender.com
```

---

## Step-by-Step Deployment

### Step 1: Deploy Backend (FastAPI)

1. Push the code to GitHub
2. Go to [Render Dashboard](https://dashboard.render.com)
3. Click **New → Web Service**
4. Connect your GitHub repo
5. Configure:
   - **Name**: `mockpilot-api`
   - **Runtime**: Python 3.13 (⚠️ NOT 3.14 — many packages lack wheel support)
   - **Region**: Oregon (or closer region)
   - **Plan**: Free (or upgrade to Starter for persistence)
   - **Build Command**: `pip install -r requirements-backend.txt`
   - **Start Command**: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
   - **Health Check Path**: `/health`

6. Set **Environment Variables** in Render Dashboard:
   ```
   GROQ_API_KEY=your-groq-api-key-here  [⚠️ REQUIRED]
   GROQ_MODEL=llama-3.3-70b-versatile
   JWT_SECRET_KEY=(auto-generated by Render)
   JWT_ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=1440
   DATABASE_URL=sqlite:///./mockpilot.db
   WHISPER_MODEL=base
   UPLOAD_DIR=uploads
   REPORTS_DIR=reports
   MAX_UPLOAD_SIZE_MB=10
   ```

7. Deploy and wait for success ✅
8. **Copy the backend URL** (e.g., `https://mockpilot-api.onrender.com`)

---

### Step 2: Deploy Frontend (Streamlit)

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **New → Web Service**
3. Configure:
   - **Name**: `mockpilot-frontend`
   - **Runtime**: Python 3.13 (⚠️ NOT 3.14 — many packages lack wheel support)
   - **Region**: Same as backend (Oregon)
   - **Plan**: Free
   - **Build Command**: `pip install -r frontend/requirements.txt`
   - **Start Command**: `streamlit run frontend/app.py --server.port=$PORT --server.address=0.0.0.0`

4. Set **Environment Variables**:
   ```
   BACKEND_URL=https://mockpilot-api.onrender.com  [⚠️ Paste backend URL from Step 1]
   ```

5. Deploy ✅

---

### Step 3: Update Backend CORS (Critical!)

1. After frontend is deployed, copy the frontend URL (e.g., `https://mockpilot-frontend.onrender.com`)
2. Go to **mockpilot-api** service → **Environment**
3. Add/Update:
   ```
   FRONTEND_URL=https://mockpilot-frontend.onrender.com
   ```
4. The backend will automatically add this to CORS origins

### Frontend (mockpilot-frontend)
- ✅ `BACKEND_URL` — Deployed FastAPI URL

## Troubleshooting

### Frontend shows "backend connection error"
- **Check**: Is `BACKEND_URL` set in frontend environment?
- **Check**: Is `FRONTEND_URL` set in backend environment?
- **Fix**: Update both, redeploy

### 401 Unauthorized errors
- **Cause**: JWT_SECRET_KEY mismatch
- **Fix**: Ensure `JWT_SECRET_KEY` is the same on backend (Render auto-generates it)

### "CORS policy" error in browser
- **Cause**: Frontend URL not in backend's CORS allowed origins
- **Fix**: Verify `FRONTEND_URL` is set in backend environment

### File uploads failing
- **Cause**: SQLite DB has no persistent storage on free tier
- **Upgrade**: Backend to Starter plan ($7/mo) for persistent disk

## Local Development vs. Production

| Setting | Local | Production |
|---------|-------|-----------|
| `BACKEND_URL` | `http://localhost:8000` | `https://mockpilot-api.onrender.com` |
| `FRONTEND_URL` | `http://localhost:8501` | `https://mockpilot-frontend.onrender.com` |
| Database | SQLite (local file) | SQLite (Render ephemeral, upgrade to Starter for persistence) |
| CORS | `*` (permissive) | Specific frontend URL (secure) |
